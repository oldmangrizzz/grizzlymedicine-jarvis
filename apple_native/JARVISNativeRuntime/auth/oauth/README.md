# JARVIS OAuth Runtime

Native OAuth support for Gemini and GitHub Copilot model heads/research tools.

## Guarantees

- OAuth 2.0 authorization-code + PKCE only; no embedded client secrets.
- Tokens are stored in macOS Keychain by `KeychainBridge/` with per-provider service names and `kSecAccessControlUserPresence` enabled by default; C++ callers use `SwiftKeychainTokenStore` in `keychain_token_store.h`.
- Refresh tokens are used automatically; refresh failure deletes the local item and raises re-auth.
- Grant, refresh, revoke, and API-call events are appended to the tamper-evident audit log. Token material is never logged.
- Every outbound OAuth/API host is in `security/pins_embedded.h`; the egress allowlist derives from that pin table.
- Cloud model calls must pass `EgressFilter`, which strips operator system context and HoloGraph-origin messages before transmission.

## Provider configuration

| Provider | OAuth endpoints | API endpoint | Scope | Rate limit |
|---|---|---|---|---:|
| Gemini | `accounts.google.com`, `oauth2.googleapis.com` | `generativelanguage.googleapis.com` | `https://www.googleapis.com/auth/generativelanguage` | 60/min |
| GitHub Copilot | `github.com/login/oauth/*` | `api.githubcopilot.com` | `read:user` | 30/min |

GitHub has no public-client RFC 7009 revoke endpoint. JARVIS cleans the local Keychain item and audits `provider_public_revoke_unavailable`; operator action is to revoke the OAuth app under GitHub Settings → Applications.

## Operator setup

1. Create provider-side OAuth clients as public/native clients.
2. Configure redirect URI `jarvis://oauth/callback` or the operator-approved loopback URI.
3. Paste only the client ID into runtime configuration. Do not add a client secret.
4. Run the authorization URL generated by `OAuthClient::authorization_url`; JARVIS exchanges the callback code using the PKCE verifier.

## Revocation

- Gemini: call `OAuthClient::revoke()`; JARVIS posts to `oauth2.googleapis.com/revoke` and deletes the Keychain item.
- GitHub Copilot: call `OAuthClient::revoke()` to delete local tokens, then revoke provider-side in GitHub Settings because no public-client revoke API is available.

## Build/test

```sh
cmake -S jarvis/apple_native/JARVISNativeRuntime/auth/oauth -B jarvis/apple_native/JARVISNativeRuntime/auth/oauth/build
cmake --build jarvis/apple_native/JARVISNativeRuntime/auth/oauth/build
ctest --test-dir jarvis/apple_native/JARVISNativeRuntime/auth/oauth/build --output-on-failure
swift test --package-path jarvis/apple_native/JARVISNativeRuntime/auth/oauth/KeychainBridge
```

Unit tests use mocked OAuth transport; they do not contact Gemini or GitHub.

## Pin rotation

See `../../security/PIN_ROTATION.md`. Rotate OAuth/API pins at least 14 days before leaf expiry and rerun OAuth + egress tests after updating `pins_embedded.h`.
